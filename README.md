This repository contains **laboratory exercises, practical implementations, and coursework** completed as part of the **Digital Image Processing (IT 3143)** module in the **Bachelor of Science in Information Technology (BSc. in IT)** program at the **University of Vavuniya, Sri Lanka**.

It focuses on **image processing techniques** implemented through day-by-day lab sessions using **Jupyter Notebooks**.

# 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/suleka-dissanayake/Digital-Image-Processing.git
   ```
2. Install the dependencies
   ```bash
   pip install numpy opencv-python matplotlib jupyter
   ```
3. Launch Jupyter and open a notebook
   ```bash
   jupyter notebook
   ```
